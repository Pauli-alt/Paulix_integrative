# ResumeLens

Formal Language-Based Resume Screening System.

## Descripción
Sistema que procesa currículums usando:
- Expresiones Regulares (extracción)
- Transductores de Estados Finitos (normalización)
- Autómatas Finitos (clasificación)
- Gramáticas Libres de Contexto (validación DSL)

## Instalación
pip install -r requirements.txt

## Uso
cd src
python main.py
